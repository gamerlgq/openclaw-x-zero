## 2026-04-01 01:27 Tools 目录学习 - Web vs Browser

### 用户问题
- 询问 tools 中的 **web browser** 和 **web tools** 分别是什么

### Tools 目录结构
从 `tools/index.md` 识别的工具分类：
- `browser` 工具 - Chromium 浏览器控制
- `web` 工具集 - `web_search` / `web_fetch` / `x_search`

### Web Tools (轻量级 HTTP 工具)

| 工具 | 功能 | 特点 |
|------|------|------|
| `web_search` | DuckDuckGo 搜索 | 无需 API key |
| `web_fetch` | 网页转 Markdown | 轻量级静态内容 |
| `x_search` | X/Twitter 搜索 | 社交媒体 |

**特点**：
- ❌ 不启动浏览器，直接 HTTP 请求
- ⚡ 快速、低资源
- 🚫 不能处理登录、JS 动态内容

### Browser Tool (完整浏览器控制)

**功能**：
- 控制 Chromium (Chrome/Brave/Edge)
- 打开/关闭标签、导航、点击、输入、拖拽、截图、PDF
- 多 Profile：`openclaw`(隔离)、`user`(真实登录 session)

**特点**：
- ✅ 完整浏览器实例，支持 JavaScript
- 🔐 可处理登录、表单、点击
- 📸 截图、PDF 导出
- 🌐 支持 Remote CDP (Browserless/Browserbase)

**CLI 命令**：
```bash
openclaw browser status
openclaw browser start
openclaw browser open https://example.com
openclaw browser snapshot
```

### 选择指南

| 场景 | 用哪个 |
|------|--------|
| 快速搜索网页 | `web_search` |
| 读取文档/文章 | `web_fetch` |
| 需登录网站 | `browser` (profile=user) |
| 点击/填表单 | `browser` |
| 截图/PDF | `browser` |
| 动态 JS 网页 | `browser` |

### 文档 URL
- tools/index.md: https://docs.openclaw.ai/tools/index.md
- tools/browser.md: https://docs.openclaw.ai/tools/browser.md (33468 字符)
- tools/web.md: https://docs.openclaw.ai/tools/web.md (13727 字符)
