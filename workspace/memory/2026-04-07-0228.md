# VPS 控制本地 macOS 多节点的最小权限方案（Node + Docker 执行隔离）

## 1. 目标

- 在 VPS 统一运行 OpenClaw Gateway。
- 多台本地 macOS 作为 Node，接入同一个 Gateway。
- 每台 macOS 的执行环境相互独立。
- 将远程执行权限收敛到受控 Docker 容器和固定挂载目录，避免直接获得 macOS 宿主机广泛权限。

## 2. 关键结论

- Node 是必需的连接层：VPS 要控制 macOS，macOS 端必须运行 node host。
- 仅开启 Gateway Docker sandbox 不能自动约束 `host=node` 在 macOS 的执行面。
- 推荐采用“混合隔离”：
 - Gateway 负责调度和策略。
 - macOS Node 负责接入。
 - macOS 本地通过包装脚本把实际执行固定到 Docker 容器（固定镜像、固定挂载、固定命令入口）。

## 3. 架构图（逻辑）

```text
[VPS]
 OpenClaw Gateway (可用 Docker 运行)
 |
 | WebSocket + Pairing + Token
 v
[macOS-A] node host ----> local docker run (sandbox-a, mount: /Users/.../workspace-a)
[macOS-B] node host ----> local docker run (sandbox-b, mount: /Users/.../workspace-b)
[macOS-C] node host ----> local docker run (sandbox-c, mount: /Users/.../workspace-c)
```

- Agent 在 Gateway 内部。
- 执行时通过 `host=node` 路由到指定 Node。
- Node allowlist 只放行“受控包装脚本”，不直接放行任意 shell。

## 4. 安全边界与风险说明

### 4.1 权限来源

- Node 默认若配置宽松，权限会较大（可在 macOS 本机执行命令）。
- 因此需要同时收紧两层：
 - Gateway 层：`tools.exec.*`（host/security/ask/node）
 - Node 层：`~/.openclaw/exec-approvals.json` allowlist

### 4.2 最小权限原则

- 不将 `bash`、`zsh`、`python3`、`docker` 主命令本体直接加入 allowlist。
- 仅 allowlist 一个固定路径包装脚本，例如：
 - `/usr/local/bin/openclaw-node-runner`
- 包装脚本内部再调用 `docker run`，并硬编码：
 - 固定镜像
 - 固定工作目录
 - 固定挂载（只挂业务目录，不挂整盘）
 - 禁止危险参数透传

### 4.3 现实边界

- 这不是形式化强隔离。若 Docker daemon 或脚本策略配置不当，仍可能放大权限。
- 生产建议：Node 使用专用 macOS 账号，不使用日常账号。

### C1. 包装脚本策略（建议）

包装脚本应满足：

- 只接受白名单子命令（如 `build`, `test`, `lint`）。
- 不接收任意 shell 字符串。
- 固定 `docker run` 镜像与挂载。
- 加资源限制（CPU/内存/ulimit）和 `--network=none`（如业务允许）。
- 容器内以非 root 运行。

示意命令（仅示意）：


openclaw dashboard --no-open 这个命令是什么意思
assistant: 这个命令有两个部分：

## `openclaw dashboard`

打开 OpenClaw 的 Web 控制台（Dashboard/UI界面），相当于一个管理后台。

功能包括：
- 查看当前会话、任务、节点状态
- 配置 Gateway 设置
- 管理已配对的设备
- 查看日志和调试信息

## `--no-open`

不自动打开浏览器。

默认情况下，执行 `openclaw dashboard` 会：
1. 启动本地Web服务（端口18789）
2. 自动打开浏览器访问控制台

加 `--no-open` 后：
- 启动Web服务
- **只打印URL，不打开浏览器**
- 适合远程访问或在终端操作

---

## 实际用途

| 场景 | 命令 |
|------|------|
| 本机快速打开UI | `openclaw dashboard` |
| 获取Token给别的机器用 | `openclaw dashboard --no-open` |
| 开机自动启动Web服务 | `openclaw gateway start`（后台运行） |
