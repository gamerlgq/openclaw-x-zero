# 素材审核规则与常见拒审原因

> 覆盖腾讯广告（微信小游戏）和巨量引擎（抖音小游戏）两大平台的广告素材审核规范
> 最后更新: 2026-04-30

---

## 一、审核流程概览

| 维度 | 腾讯广告 | 巨量引擎 |
|------|---------|---------|
| **审核时效** | 工作日 24h 内，周末/节假日 48h 内，通常 4-5 小时 | 通常 1-2 小时，节假日可能延长 |
| **提交方式** | 投放管理平台提交，API 创建的创意也需过审 | 广告投放平台提交，API 创建也需过审 |
| **复审机制** | 广告列表 → 查看详情 → 我要复审 → 提交需求 | 审核驳回后可修改重提 |
| **建议** | 提前 3-5 个工作日上广告审核 | 提前 1-2 天上审 |

## 二、通用审核红线（两平台共通）

### 2.1 绝对化用语

**禁止使用**：
- 国家级、最高级、最佳、顶级、第一、极品、至尊
- 例外：有权威机构证明（如"XX大赛第一名"+获奖证明）、时空顺序表述（如"首款"）、经营理念（如"顾客第一"）

### 2.2 法律法规红线

| 红线 | 说明 |
|------|------|
| 涉政涉赌 | 禁止涉政、涉赌内容，棋牌类（老虎机、百家乐等）禁止 |
| 色情低俗 | 禁止暴露、挑逗、暗示性内容 |
| 虚假欺诈 | 禁止虚假红包、虚假倒计时、虚假活动 |
| 黑灰产 | 禁止私服、外挂、账号买卖、提现、装备现金交易 |
| 侵权 | 使用第三方 IP（动漫人物、标志性图标）需授权资质 |
| 国旗国徽 | 禁止使用国旗、国徽、军旗等（政府宣传除外） |

### 2.3 诱导行为

**禁止**：
- 诱导分享、诱导添加、诱导关注、诱导下载
- "通宵打关"、"已经玩了10几个小时了"
- 利益诱惑诱导传播（分享才能继续/领取）
- 夸张言语胁迫/引诱用户分享
- 虚假倒计时催促

### 2.4 素材格式规范

| 规范 | 说明 |
|------|------|
| 文字占比 | 外层素材文字占比 ≤ 30% |
| 二维码 | 广告中不允许展示任何二维码 |
| 联系方式 | 不允许展示个人微信号/QQ号/手机号 |
| 悬浮元素 | 浮层堆砌 ≥ 3 或占比 > 50% → 拒审 |
| 过曝发光 | 发光面积 > 30%、刺眼不适 → 拒审（腾讯新闻流量） |

## 三、游戏行业专项审核规则

### 3.1 资质要求

**腾讯广告**：
- 《国产网络游戏备案通知单》（文化部备案）
- 《网络游戏出版物号（ISBN）核发单》（版署版号）

**巨量引擎**：
- 游戏版号 + 软著（名称需完全一致）
- 企业营业执照（个人开发者需身份证）

### 3.2 游戏广告专属禁止项

| # | 禁止内容 | 说明 |
|---|---------|------|
| 1 | 赌博类关键词 | 老虎机、百家乐、骰宝、21点、牌九、梭哈、扎金花、赢三张、牛牛、德州 |
| 2 | 诱导性可玩性描述 | "通宵打关"、"已经玩了10几个小时了" |
| 3 | 夸大内容 | 与实际游戏不符的夸张描述 |
| 4 | 账号/装备交易 | 账号买卖、提现、装备现金交易 |
| 5 | 不实盈利描述 | "装备全靠打"、"无付费无商城"（与实际盈利不符） |
| 6 | 招商加盟 | 禁止游戏招商、代理、棋牌定制 |
| 7 | 官场/低俗 | 角色扮演类不得涉及官场、选妃、三妻四妾等 |
| 8 | 混淆诱导按钮 | 非游戏内的关闭按钮、抽奖按钮等诱导点击元素 |
| 9 | 相同物品图标堆砌 | 领取类广告，相同物品图标 ≤ 2 个（QQ流量） |
| 10 | 掉落物过多 | 整体图片掉落物 ≤ 5 个（新闻/视频流量） |
| 11 | 引导外链 | 跳转淘宝/京东等第三方平台（腾讯广告禁止一跳） |

### 3.3 小游戏特殊审核（抖音平台）

| # | 规范 | 说明 |
|---|------|------|
| 1 | 页面完整性 | 不能白屏、崩溃、闪退 |
| 2 | 返回导航 | 多级页面需有返回方式 |
| 3 | 按钮规范 | 不可重叠、不可操作下层、功能与描述一致 |
| 4 | 视频广告标识 | 触发广告的按钮需有明显视频广告标识 |
| 5 | 诱导下载 | 禁止引导下载 APP |
| 6 | iOS 支付 | 小游戏内 iOS 端禁止提供任何付费途径/入口 |
| 7 | 广告遮挡 | 广告占比不超过 50%，不可遮挡核心功能 |
| 8 | 隐私合规 | 采集用户数据需明示同意，禁止首屏强制授权 |
| 9 | 重复授权 | 禁止多页面重复授权相同信息 |
| 10 | 自动播放 | 禁止视频/音乐/语音自动播放 |

## 四、常见拒审原因与解决方案

### 4.1 腾讯广告高频驳回（黄底重点）

| 排名 | 驳回原因 | 解决方案 |
|------|---------|---------|
| 1 | 绝对化用语 | 替换为"热门"、"人气"等非绝对化表述 |
| 2 | 外层素材文字占比过大 | 精简文案，控制在 30% 以内 |
| 3 | 夸大/虚假宣传 | 使用真实游戏画面，删除无法证实的描述 |
| 4 | 诱导分享/下载 | 去除"立即分享解锁"、"下载领取"等引导 |
| 5 | 二维码/个人联系方式 | 移除所有二维码，使用平台组件（如企微组件） |
| 6 | 行业不一致 | 确保开户行业与推广内容匹配 |
| 7 | 涉及第三方品牌/IP | 提供授权资质（3-5 份）或删除相关元素 |
| 8 | 涉及知名人士肖像 | 提供人物形象授权或替换素材 |
| 9 | 限时限量无证明 | 标注具体活动时间+数量，上传盖章备案 |
| 10 | 警示语不清晰 | 字体 ≥ 25px，清晰可识别 |

### 4.2 巨量引擎高频驳回

| 排名 | 驳回原因 | 解决方案 |
|------|---------|---------|
| 1 | 素材与实际不符（货不对板） | 使用真实游戏画面，禁止影视素材冒充 |
| 2 | 虚假诱导按钮（红包、暂停、清理） | 移除误导性 UI 元素 |
| 3 | 过度承诺效果 | 删除"包过"、"必赢"等承诺性用语 |
| 4 | 低俗/擦边内容 | 替换暴露角色形象，调整文案表述 |
| 5 | 暴力血腥画面 | 降低暴力程度，使用卡通化表现 |
| 6 | 涉及赌博元素 | 移除棋牌赢取现金、提现等描述 |
| 7 | iOS 支付引导 | 删除所有 iOS 端付费入口 |
| 8 | 隐私授权违规 | 首屏不强制授权，用户可拒绝后继续使用 |

### 4.3 小游戏特定拒审场景

| 场景 | 驳回原因 | 解决方案 |
|------|---------|---------|
| 视频广告按钮无标识 | 触发视频广告的按钮未标注"广告" | 按钮上增加明显的视频广告 icon |
| 签到奖励无限领取 | 逻辑漏洞，同一奖励可重复获取 | 确保签到奖励仅可领取一次 |
| 分享才能继续 | 强制分享才能推进游戏 | 改为可选分享，不阻断游戏进程 |
| 悬浮广告遮挡功能 | 广告面积 > 50% 或遮挡核心按钮 | 调整广告布局，确保功能可用 |
| iOS 端有付费入口 | iOS 版小游戏展示定价/购买按钮 | iOS 端移除所有付费相关 UI |
| 首屏强制授权 | 打开即弹授权弹窗 | 延迟到用户实际需要时再请求授权 |
| 多页面重复授权 | 每个页面都弹授权 | 授权一次后全局生效 |

## 五、审核加速技巧

### 5.1 提审前自查清单

- [ ] 素材文字占比 ≤ 30%
- [ ] 无绝对化用语
- [ ] 无二维码/个人联系方式
- [ ] 无诱导分享/下载/关注
- [ ] 游戏素材为真实画面，非影视剧混淆
- [ ] 无赌博/色情/暴力元素
- [ ] iOS 端无付费入口
- [ ] 隐私协议已添加且未默认勾选
- [ ] 警示语清晰（≥ 25px）
- [ ] 行业与开户一致
- [ ] 资质齐全（版号、软著）

### 5.2 提审时间建议

| 平台 | 建议 |
|------|------|
| 腾讯广告 | 提前 3-5 个工作日，避免节假日前夕集中提审 |
| 巨量引擎 | 提前 1-2 天，工作日上午提审通过更快 |

### 5.3 被驳回后处理

**腾讯广告**：
1. 广告列表 → 查看详情 → 查看驳回原因
2. 修改后重新提交
3. 如有疑义 → 我要复审 → 描述需求 → 专人核实
4. 仍无法解决 → 联系运营人员

**巨量引擎**：
1. 查看驳回原因及具体描述
2. 修改素材/文案后重新提交
3. 多次驳回同类问题 → 可能触发账户风控 → 需联系运营

## 六、两平台审核对比

| 维度 | 腾讯广告 | 巨量引擎 |
|------|---------|---------|
| **审核时效** | 工作日 24h（通常 4-5h） | 通常 1-2h |
| **游戏资质** | 文化部备案 + ISBN 版号 | 版号 + 软著 |
| **素材文字占比** | ≤ 30% | ≤ 30% |
| **二维码** | 禁止（企微组件除外） | 禁止 |
| **绝对化用语** | 禁止（有证明除外） | 禁止 |
| **iOS 支付** | 不涉及（微信小游戏无此限制） | 严格禁止 iOS 端付费入口 |
| **视频广告标识** | 朋友圈需 link_name_type=ENTER_MINI_GAME | 触发按钮需明显广告标识 |
| **棋牌类** | 部分流量禁止（新闻/视频流量） | 禁止涉赌内容 |
| **复审机制** | 我要复审 → 专人核实 | 修改重提 |
| **违规处罚** | 按帮助中心违规处罚规范 | 多次违规可能触发账户风控 |
| **小游戏功能审核** | 腾讯侧审核 | 抖音开放平台审核 + 广告审核双重 |
