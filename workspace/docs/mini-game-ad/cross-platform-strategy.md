# 跨平台投放策略：微信 + 抖音联合买量

> 覆盖微信小游戏与抖音小游戏的双端投放策略、用户差异、素材适配、数据归因与联合增长
> 最后更新: 2026-04-30

---

## 一、为什么必须双端投放？

### 1.1 市场现状（2025-2026）

| 指标 | 微信小游戏 | 抖音小游戏 |
|------|-----------|-----------|
| MAU | 5亿+（2025） | 日均时长同比+47% |
| 在投小游戏数增长 | +165% | 快速增长中 |
| 广告消耗增长 | +20%（IAA +30%） | 消耗峰值持续突破 |
| 开发者规模 | 40万+（80%为30人以下团队） | 快速追赶 |
| 百万DAU游戏 | 近70款 | — |
| 千万流水/季度 | 300+款 | 头部爆款频出 |

**核心结论**：单端投放已不足以支撑规模化增长，微信有社交裂变 + PC 蓝海，抖音有内容驱动 + 算法分发，两者用户重合度低，互补性强。

### 1.2 平台核心差异

| 维度 | 微信小游戏 | 抖音小游戏 |
|------|-----------|-----------|
| **分发逻辑** | 社交裂变（分享、群聊、搜一搜） | 内容驱动（短视频、直播、信息流推荐） |
| **用户画像** | 女性用户占70%曝光；年龄层更广；偏休闲 | 年轻化，男性偏策略/动作，女性偏解谜/模拟 |
| **入口方式** | 即点即玩（小程序/分享链接） | 即点即玩（短视频挂载/直播挂载/信息流） |
| **变现模式** | IAP 为主（内购），IAA 增速快（+30%） | IAA 为主，正向 IAP/混合变现转型 |
| **分成比例** | 安卓 IAP 四六开（开发者60%） | IAP 最高25%激励，IAA 广告场景收益全返+10%激励 |
| **PC端** | PC小游戏用户+55%，付费意愿1.5倍移动端 | 暂无PC端 |
| **内容营销** | 视频号直播+短视频CPS | 短视频+直播（小游戏直播流水超达人视频） |
| **流量成本** | 移动端竞争白热化，PC端获客成本低60% | 信息流竞争激烈，直播/达人带货成本相对可控 |

## 二、双端投放策略框架

### 2.1 品类-平台匹配矩阵

| 游戏品类 | 微信优先级 | 抖音优先级 | 原因 |
|----------|-----------|-----------|------|
| 消除/合成/休闲解谜 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | 微信女性用户70%，匹配度最高 |
| 模拟经营 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 双端均有好表现 |
| RPG/卡牌 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 抖音男性用户偏策略/RPG |
| IAP 重度游戏 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 微信内购生态更成熟 |
| IAA 轻度游戏 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 抖音IAA变现+ROI出价极强 |
| IAAP 混合变现 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 微信内购+广告双引擎 |

### 2.2 投放节奏：从单端到双端

```
第1阶段：单端测试（1-2周）
    ├─ 选择主战场（根据品类）
    ├─ 小预算测试出价/素材/定向
    └─ 验证 CPA / ROI 是否达标

第2阶段：双端放量（2-4周）
    ├─ 同款游戏双端同时投放
    ├─ 各端独立出价策略（见出价策略篇）
    └─ 素材二次适配（见素材适配节）

第3阶段：双端协同（持续）
    ├─ 数据归因打通（见归因节）
    ├─ 跨端 LTV 对比优化
    └─ 激励政策组合（见激励政策节）
```

## 三、投放实操对比

### 3.1 账户与基建

| 配置项 | 微信（腾讯广告） | 抖音（巨量引擎） |
|--------|----------------|-----------------|
| **开户** | 腾讯广告投放平台 | 巨量引擎工作台 |
| **资产创建** | 小游戏AppID绑定 | 广告投放平台→资产→小程序/小游戏 |
| **推广目标** | `PROMOTED_OBJECT_TYPE_MINI_GAME_WECHAT` | 小游戏推广 |
| **投放层级** | 广告→创意（2层） | V3: 项目→广告（2层）；旧版: 计划→广告组→创意（3层） |
| **基建标准** | 单游戏5-10条在投 | 单产品5账户×5项目×5广告×5素材 |
| **版位** | 朋友圈/公众号/小程序/视频号/搜一搜/优量汇 | 抖音信息流/抖音直播/穿山甲/头条/西瓜 |

### 3.2 出价策略差异化

| 阶段 | 微信（腾讯广告） | 抖音（巨量引擎） |
|------|-----------------|-----------------|
| **冷启动** | 注册 oCPM，出价=预期CPA×1.2 | 激活/注册 oCPM，出价=预期CPA×1.3 |
| **起量期** | 注册+首付深度优化 / 注册+次留 | 关键行为 oCPM → ROI 出价 |
| **稳定期（IAA）** | 广告变现 oCPM / 注册+次留 | ROI 出价（核心） |
| **稳定期（IAP）** | 首次付费 oCPM | 付费 oCPM / ROI 出价 |
| **稳定期（IAAP）** | 首付 oCPM 或 广告变现 oCPM | ROI 出价 + 付费优化 |

### 3.3 素材适配

| 维度 | 微信 | 抖音 |
|------|------|------|
| **素材格式** | 图片（朋友圈9图）、视频（15-30s）、小程序直投 | 视频（竖屏6-30s）、图片信息流、直播切片 |
| **文案风格** | 社交感（朋友推荐、群聊分享）、偏温和 | 内容感（短剧/挑战/搞笑）、偏冲击力 |
| **落地页** | 小游戏直接打开（无需下载） | 小游戏直接打开（无需下载） |
| **关键差异** | 朋友圈需要 link_name_type=ENTER_MINI_GAME | 视频素材需要录屏功能支持 |
| **审核要点** | 文字占比≤30%，无二维码 | 按钮需有广告标识，iOS无付费入口 |
| **素材复用** | 抖音竖屏视频 → 微信视频号版位 | 微信横屏素材 → 抖音信息流（需裁切适配） |

**素材跨端适配核对表**：
- [ ] 视频比例：微信横竖均可，抖音优先9:16竖屏
- [ ] 文案语言：微信偏温和社交，抖音偏冲击力内容
- [ ] CTA按钮：微信"进入游戏"，抖音"立即试玩"
- [ ] 审核适配：两平台分别过审后再投放
- [ ] 录屏功能：抖音端需内置录屏支持（技术适配）

## 四、数据归因与效果对比

### 4.1 归因方式差异

| 维度 | 微信（腾讯广告） | 抖音（巨量引擎） |
|------|-----------------|-----------------|
| **归因口径** | 注册归因（基于 `__CALLBACK__` + `click_id`） | 点击归因（基于 clickid/callback url+token） |
| **核心标识** | `wechat_openid` + `wechat_app_id` | `callback url` + `event_type` |
| **回传接口** | `tracking.e.qq.com/conv` 或 `api.e.qq.com/v3.0/user_actions/add` | 事件管理平台 API / url+token 回调 |
| **回传时效** | ≤5分钟（推荐实时） | ≤5分钟（推荐实时） |
| **鉴权升级** | 2025Q3起强制 HTTPS+access-token | OAuth 2.0 + access_token |
| **第三方归因** | DataNexus / AppsFlyer / 热力引擎 | SolarEngine / TrackingIO / 热力引擎 |

### 4.2 跨端数据打通方案

由于微信和抖音用户体系不互通，跨端归因无法精确到用户级别，但可通过以下方式做宏观对比：

| 方法 | 说明 |
|------|------|
| **统一第三方归因平台** | 接入热力引擎/SolarEngine，双端数据统一面板查看 |
| **LTV 对比** | 分别统计两端的 LTV7/LTV14/LTV30，对比投入产出 |
| **ROI 对比** | 微信 ROI = 内购收入÷消耗；抖音 ROI = (内购+广告变现)÷消耗 |
| **分群AB测试** | 同一素材/策略在两端分别测试，观察效果差异 |
| **激励政策组合** | 分别计算两端的广告金/分成返还，综合ROI |

### 4.3 第三方归因平台选型

| 平台 | 微信 | 抖音 | 快手 | 特点 |
|------|------|------|------|------|
| **热力引擎** | ✅ | ✅ | ✅ | 行为分析+分群+回传，适合中小团队 |
| **SolarEngine** | ✅ | ✅ | — | IAA 归因专业，回传灵活 |
| **TrackingIO** | ✅ | ✅ | ✅ | 老牌归因，功能全面 |
| **DataNexus** | ✅ | — | — | 腾讯官方，微信生态最深度 |
| **AppsFlyer** | ✅ | ✅ | — | 全球化，适合出海 |

## 五、激励政策与成本优化

### 5.1 当前激励政策（2026年暑期）

| 政策 | 微信小游戏 | 抖音小游戏 |
|------|-----------|-----------|
| **IAP分成** | 安卓四六开（开发者60%） | 最高25%激励 |
| **IAA激励** | 广告消耗10%广告金（增速达标，上限500万） | 广告场景收益全返 + 最高10%广告金 |
| **PC端专属** | PC内购额外10%广告金 | — |
| **新游扶持** | 新游冷启动流量包 | 免费启动流量 |

### 5.2 成本优化策略

| 策略 | 微信 | 抖音 |
|------|------|------|
| **PC蓝海** | PC端获客成本低60%，PC用户付费1.5倍移动端 | — |
| **搜一搜** | IAA品类搜一搜消耗近翻倍 | — |
| **视频号直播** | 小游戏直播CPS，低CAC获客 | 短视频+直播挂载，达人带货 |
| **内容营销** | 视频号互选+广告联投 | 达人视频+直播，低成本拉新增 |
| **ROI出价** | 注册+首日付费ROI（灰度） | ROI出价成熟产品，100%必用 |

### 5.3 联合买量预算分配建议

| 游戏类型 | 微信预算占比 | 抖音预算占比 | 说明 |
|----------|------------|------------|------|
| IAA 轻度 | 40% | 60% | 抖音ROI出价效率更高 |
| IAP 中重度 | 60% | 40% | 微信内购生态+PC端更成熟 |
| IAAP 混合 | 50% | 50% | 根据数据动态调整 |
| 新游测试 | 30% | 70% | 抖音起量更快，适合验证 |

> 预算分配应根据实际数据每1-2周动态调整，以上比例为初始参考。

## 六、常见问题

### Q1: 同一款游戏能否同时投微信和抖音？
**可以**。技术层面小游戏代码跨平台复用率高（CocosCreator/Laya/Ant引擎均支持多端发布），需注意：
- 抖音端需增加录屏功能
- iOS 端抖音不允许任何付费入口
- 两端分别过审

### Q2: 用户重合度高吗？会不会浪费预算？
**重合度较低**。微信用户偏社交驱动、年龄层广、女性占70%曝光；抖音用户偏内容驱动、年轻化、男女品类偏好差异大。核心玩家重合度有限，双端投放更多是增量而非内耗。

### Q3: 双端数据如何统一看？
建议接入统一第三方归因平台（如热力引擎），双端数据在同一面板查看。无法精确到用户级别去重，但可做宏观数据对比和ROI核算。

### Q4: 先投哪个平台？
- IAA 轻度游戏 → 先抖音（ROI出价成熟、起量快）
- IAP 中重度游戏 → 先微信（内购生态成熟、PC端增量）
- 不确定 → 双端小预算同步测试，7天后看数据决定加码方向

### Q5: 素材能否直接复用？
**需要适配**：
- 视频比例：微信横竖均可，抖音优先9:16竖屏
- 文案风格：微信偏温和社交，抖音偏冲击力内容
- 审核标准：两平台规则不同，分别过审
- 建议制作"通用版"（竖屏+中性文案），再微调

### Q6: PC端小游戏值不值得投？
**值得**。微信PC小游戏用户活跃+55%，商业规模+40%，付费意愿1.5倍移动端，获客成本低60%。应用宝PC跨端广告消耗+400%，7日ROI+50%。
