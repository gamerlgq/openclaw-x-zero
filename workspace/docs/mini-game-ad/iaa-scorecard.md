## 一、核心指标定义

### 1.1 获客指标

| 指标 | 英文 | 公式 | 说明 |
|------|------|------|------|
| CPA | Cost Per Acquisition | 消耗 ÷ 激活数 | 获取一个激活用户的成本 |
| CPR | Cost Per Register | 消耗 ÷ 注册数 | 获取一个注册用户的成本 |
| CTR | Click-Through Rate | 点击数 ÷ 曝光数 × 100% | 素材点击率 |
| CVR | Conversion Rate | 注册数 ÷ 点击数 × 100% | 注册转化率 |
| 激活成本 | Activate CPA | 消耗 ÷ 激活数 | 点击→激活的成本 |

### 1.2 留存指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 次留 D1 | 次日回访用户 ÷ 当日新增用户 × 100% | 最核心的留存指标 |
| 3日留存 D3 | 第3日回访 ÷新增 × 100% | 短期留存 |
| 7日留存 D7 | 第7日回访 ÷新增 × 100% | 中期留存，判断游戏粘性 |
| 14日留存 D14 | 第14日回访 ÷新增 × 100% | 长线留存 |
| 30日留存 D30 | 第30日回访 ÷新增 × 100% | 游戏生命周期判断 |

### 1.3 变现指标

| 指标 | 英文 | 公式 | 说明 |
|------|------|------|------|
| ARPU | Avg Revenue Per User | 总收入 ÷ 活跃用户数 | 单用户平均收入 |
| ARPPU | Avg Revenue Per Paying User | 总收入 ÷ 付费用户数 | 付费用户人均收入 |
| eCPM | Effective Cost Per Mille | (广告收入 ÷ 广告展示次数) × 1000 | 千次广告展示收入 |
| 广告展示频次 | Ad Impression / DAU | 广告展示次数 ÷ DAU | 人均看广告次数 |
| 渗透率 | Ad Penetration | 看广告用户 ÷ DAU × 100% | 多少比例用户看了广告 |
| IAA 收入占比 | — | 广告收入 ÷ 总收入 × 100% | 广告变现收入占比 |

### 1.4 回本指标

| 指标 | 公式 | 说明 |
|------|------|------|
| LTV N | 第N天累计人均收入 | 单用户第N天累计贡献收入 |
| ROI N | LTV N ÷ CPA × 100% | 第N天回本率 |
| 回本周期 | LTV = CPA 时的天数 | 收回获客成本所需天数 |
| 日利润 | 日收入 - 日消耗 | 每日净赚/亏 |

## 五、诊断决策树

```
ROI D7 < 50%？
├─ 是 → CPA > 行业合格线？
│   ├─ 是 → 获客效率差
│   │   ├─ CTR 低 → 换素材
│   │   ├─ CVR 低 → 优化落地页/注册流程
│   │   └─ CTR+CVR 正常 → 出价过高，降出价或切ROI出价
│   └─ 否 → ARPU/eCPM 低
│       ├─ 渗透率低 → 优化广告点位和激励逻辑
│       ├─ 展示频次低 → 增加广告场景（插屏/激励视频）
│       └─ eCPM低 → 提升广告填充/检查SDK接入
└─ 否 → D1留存在30%以下？
    ├─ 是 → 产品留存差
    │   ├─ 次留<25% → 新手引导/核心玩法需改
    │   └─ 次留OK但7留差 → 长线内容不足
    └─ 否 → 回本周期>15天？
        ├─ 是 → LTV曲线衰减快
        │   ├─ 优化留存保活
        │   └─ 增加广告场景触达
        └─ 否 → 模型健康，可加量
```

## 六、自动评分脚本（Python）

```python
#!/usr/bin/env python3
"""IAA 游戏关键指标评分卡 - 自动计算版"""

def score(value, benchmarks):
    """
    benchmarks: [(upper_bound, score), ...] 按从低到高排列
    对于越大越好的指标: benchmarks 从低到高
    对于越小越好的指标: benchmarks 从高到低（需反转逻辑）
    """
    for threshold, s in benchmarks:
        if value <= threshold:
            return s
    return benchmarks[-1][1]

# ============ 填写实际数据 ============
GAME_NAME = "示例游戏-消除类"
PLATFORM = "微信"
CATEGORY = "消除"

# 获客指标
CPA = 18          # 元
CTR = 2.1          # %
REG_CVR = 28       # %

# 留存指标
D1 = 38            # %
D7 = 12            # %
D30 = 3.5          # %

# 变现指标
ECPM = 65          # 元
ARPU = 0.35        # 元/日
AD_PENETRATION = 35  # %

# 回本指标
ROI_D7 = 55       # %
PAYBACK_DAYS = 9   # 天

# ============ 评分逻辑 ============
# 越小越好
def score_lower(value, thresholds):
    """thresholds: [(最大优秀值, 5分), (最大良好, 4分), ...]"""
    for upper, s in thresholds:
        if value <= upper:
            return s
    return 1

# 越大越好
def score_higher(value, thresholds):
    """thresholds: [(最低5分值, 5分), (最低4分值, 4分), ...]"""
    for lower, s in thresholds:
        if value >= lower:
            return s
    return 1

scores = {}
scores['CPA'] = score_lower(CPA, [(5, 5), (15, 4), (30, 3), (50, 2)])
scores['CTR'] = score_higher(CTR, [(3.0, 5), (2.0, 4), (1.0, 3), (0.5, 2)])
scores['CVR'] = score_higher(REG_CVR, [(40, 5), (25, 4), (15, 3), (8, 2)])
scores['D1'] = score_higher(D1, [(45, 5), (35, 4), (25, 3), (15, 2)])
scores['D7'] = score_higher(D7, [(20, 5), (15, 4), (8, 3), (5, 2)])
scores['D30'] = score_higher(D30, [(8, 5), (5, 4), (3, 3), (1.5, 2)])
scores['eCPM'] = score_higher(ECPM, [(150, 5), (80, 4), (40, 3), (20, 2)])
scores['ARPU'] = score_higher(ARPU, [(1.0, 5), (0.5, 4), (0.2, 3), (0.1, 2)])
scores['渗透率'] = score_higher(AD_PENETRATION, [(60, 5), (40, 4), (25, 3), (15, 2)])
scores['ROI_D7'] = score_higher(ROI_D7, [(120, 5), (80, 4), (50, 3), (30, 2)])
scores['回本周期'] = score_lower(PAYBACK_DAYS, [(3, 5), (7, 4), (15, 3), (30, 2)])

# 权重
WEIGHTS = {
    'CPA': 20, 'CTR': 20, 'CVR': 20,
    'D1': 15, 'D7': 10, 'D30': 10,
    'eCPM': 10, 'ARPU': 10, '渗透率': 10,
    'ROI_D7': 15, '回本周期': 10,
}

total = sum(scores[k] * WEIGHTS[k] / 5 for k in scores)
max_total = sum(WEIGHTS.values())

print(f"\n{'='*50}")
print(f"  IAA 游戏评分卡 - {GAME_NAME} ({PLATFORM})")
print(f"{'='*50}")
print(f"{'指标':<10} {'实际值':<10} {'评分':<6} {'权重':<6} {'加权分':<8}")
print(f"{'-'*50}")
for k in scores:
    v = eval(k.replace('渗透率','AD_PENETRATION').replace('ROI_D7','ROI_D7').replace('回本周期','PAYBACK_DAYS'))
    print(f"{k:<10} {v:<10} {scores[k]:<6} {WEIGHTS[k]:<6} {scores[k]*WEIGHTS[k]/5:<8.1f}")
print(f"{'-'*50}")
print(f"{'总计':<10} {'':10} {'':6} {max_total:<6} {total:<8.1f}/{max_total}")
print(f"{'='*50}")

pct = total / max_total * 100
if pct >= 87: grade = "A+ 可加大投放"
elif pct >= 73: grade = "A  持续优化稳步放量"
elif pct >= 60: grade = "B  达标，需针对性优化"
elif pct >= 47: grade = "C  及格线，重点突破短板"
elif pct >= 33: grade = "D  需重新评估"
else: grade = "F  建议止损"
print(f"\n综合评级: {grade} ({pct:.0f}分)")
```
