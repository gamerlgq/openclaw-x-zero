# 国内IAA小游戏盈利数据模型

> 基于行业公开数据构建的IAA游戏盈利测算模型，含具体数值参考
> 最后更新: 2026-04-30

---

## 一、核心公式体系

### 1.1 基础公式

```
日收入 = DAU × IPU × (eCPM / 1000)
LTV_N = Σ(第i日留存率 × ARPU_Di)  (i=1到N)
ROI_N = LTV_N / CPA × 100%
日利润 = 日收入 - 日消耗 - 运营成本
回本周期 = LTV = CPA 时的天数
```

### 1.2 变量定义

| 变量 | 含义 | 单位 |
|------|------|------|
| DAU | 日活跃用户 | 人 |
| IPU | 人均广告展示次数 (Impression Per Unit) | 次/人/日 |
| eCPM | 千次展示有效收入 | 元/千次 |
| CPA | 单用户获取成本 | 元/人 |
| ARPU | 单用户日平均收入 | 元/人/日 |
| LTV | 用户生命周期价值 | 元/人 |

## 三、盈利模型（具体数值版）

### 3.1 模型A：合格线模型（能活）

```
参数设定（行业平均偏下）：
- 日均消耗: 5,000元
- CPA: 15元
- 日新增: 333人 (5000÷15)
- D1留存: 25%
- D7留存: 8%
- eCPM: 40元
- IPU: 5次/人/日
- 广告渗透率: 35%

日收入计算：
DAU ≈ 日新增 × (1 + D1 + D3 + D7加权) ≈ 333 × 1.5 ≈ 500人
实际广告用户 = DAU × 渗透率 = 500 × 35% = 175人
日展示 = 175 × 5 = 875次
日收入 = 875 × (40/1000) = 35元

结论：日收入35元 < 日消耗5000元 → 严重亏损
需要日新增达到 5000÷(40/1000×5×35%)÷1.5 ≈ 47,619人才能盈亏平衡
```

### 3.2 模型B：优秀模型（能赚钱）

```
参数设定（行业优秀水平）：
- 日均消耗: 10,000元
- CPA: 8元
- 日新增: 1,250人
- D1留存: 40%
- D7留存: 15%
- eCPM: 80元
- IPU: 8次/人/日
- 广告渗透率: 55%

日收入计算：
DAU ≈ 1250 × 2.0 = 2,500人
广告用户 = 2500 × 55% = 1,375人
日展示 = 1375 × 8 = 11,000次
日收入 = 11000 × (80/1000) = 880元

日利润 = 880 - 10000 = -9120元（仍在亏损）

LTV估算（7天）：
LTV7 ≈ ARPU × 留存天数加权
ARPU = 880/2500 = 0.35元/人/日
LTV7 ≈ 0.35 × (1 + 0.4 + 0.25 + 0.15×4) ≈ 0.35 × 2.5 = 0.875元
ROI7 = 0.875/8 = 10.9%（远未回本）

问题：CPA 8元，LTV7只有0.875元，完全无法回本
→ 此模型参数组合下无法盈利
```

### 3.3 模型C：头部盈利模型（真能赚）

```
参数设定（头部水平，高留存+高变现）：
- 日均消耗: 20,000元
- CPA: 5元（通过自然量+付费混合拉低）
- 日新增: 4,000人（含2,000自然量，2,000付费量）
- D1留存: 50%
- D7留存: 22%
- D30留存: 8%
- eCPM: 100元
- IPU: 10次/人/日
- 广告渗透率: 65%

日收入计算：
DAU ≈ 4000 × 2.5 = 10,000人
广告用户 = 10000 × 65% = 6,500人
日展示 = 6500 × 10 = 65,000次
日收入 = 65000 × (100/1000) = 6,500元

日利润 = 6500 - 20000 = -13,500元（还在亏）

但注意：这是首日数据，留存用户持续贡献收入

LTV30估算：
ARPU = 6500/10000 = 0.65元/人/日
LTV30 ≈ 0.65 × (1 + 0.5 + 0.35 + 0.22 + 0.15 + 0.12 + 0.10 + 0.08×23)
      ≈ 0.65 × 5.0 = 3.25元

ROI30 = 3.25/5 = 65%（30天回本65%，还未完全回本）

要达到盈亏平衡，需要：
- 降低CPA到3元以下，或
- 提高eCPM到150+，或
- 提高留存（D1>60%, D7>30%），或
- 提高IPU到15+，或
- 混合变现加入IAP
```

### 3.4 模型D：IAAP混合变现模型（推荐）

```
参数设定（IAA+IAP混合，当前最可行）：
- 日均消耗: 15,000元
- CPA: 6元（付费用户）
- 日新增: 2,500人
- D1留存: 45%
- D7留存: 18%
- eCPM: 70元（IAA部分）
- IPU: 7次/人/日
- 广告渗透率: 50%
- 付费率: 3%
- ARPPU: 30元

日收入计算：
DAU ≈ 2500 × 2.2 = 5,500人

IAA收入：
广告用户 = 5500 × 50% = 2,750人
日展示 = 2750 × 7 = 19,250次
IAA收入 = 19250 × (70/1000) = 1,347.5元

IAP收入：
付费人数 = 2500 × 3% = 75人
IAP收入 = 75 × 30 = 2,250元

总收入 = 1347.5 + 2250 = 3,597.5元
日利润 = 3597.5 - 15000 = -11,402.5元（首日仍亏）

LTV30估算：
IAA LTV30 ≈ (1347.5/5500) × 4.5 = 1.10元
IAP LTV30 ≈ (2250/2500) × 2.0 = 1.80元（复购衰减）
总LTV30 = 2.90元
ROI30 = 2.90/6 = 48.3%

结论：纯买量模式下，即使IAAP混合，30天也难以完全回本
→ 必须依靠自然量降低综合CPA，或延长LTV到90天+
```

## 四、盈利临界条件分析

### 4.1 单用户盈利条件

要使单用户盈利，需要：

```
LTV > CPA

即：ARPU × 留存周期 > CPA

变形：ARPU > CPA / 留存周期

示例：
- CPA = 10元
- 平均留存周期 = 10天
- 则 ARPU 必须 > 1元/日

或：
- ARPU = 0.5元/日
- 留存周期 = 20天
- 则 CPA 必须 < 10元
```

### 4.2 日利润盈亏平衡

```
日利润 = 日收入 - 日消耗 > 0

即：DAU × 渗透率 × IPU × (eCPM/1000) > 日消耗

变形：DAU > 日消耗 / (渗透率 × IPU × eCPM/1000)

示例：
- 日消耗 = 10,000元
- 渗透率 = 50%
- IPU = 6
- eCPM = 50元
- 需要 DAU > 10000 / (0.5 × 6 × 0.05) = 66,667人

这意味着：在eCPM 50元、IPU 6次的情况下
需要日活6.7万才能盈亏平衡1万的日消耗
```

### 4.3 关键杠杆点

| 杠杆 | 当前值 | 提升20%后 | 对收入影响 |
|------|--------|----------|-----------|
| eCPM | 50元 | 60元 | +20% |
| IPU | 6次 | 7.2次 | +20% |
| 渗透率 | 40% | 48% | +20% |
| D1留存 | 30% | 36% | +20% DAU |
| CPA | 15元 | 12元 | 成本-20% |

> 注：提升留存对DAU的影响是复利效应，长期收益最大

## 五、不同规模游戏的盈利路径

### 5.1 小团队（1-5人）

**目标**：月利润 5-20万
**路径**：
- 选择低CPA品类（解谜/找茬/合成）
- CPA控制在5元以内
- 靠自然量（50%）+ 付费量（50%）降低综合成本
- 日新增目标：5000-10000人
- 月消耗：10-30万
- 月利润：5-20万

### 5.2 中型团队（10-30人）

**目标**：月利润 50-200万
**路径**：
- 多品类矩阵（3-5款游戏）
- 每款日消耗1-3万
- 单款DAU目标：3-5万
- 重点优化留存和IPU
- 引入IAP混合变现
- 月消耗：100-300万
- 月利润：50-200万

### 5.3 大型团队（50人+）

**目标**：月利润 500万+
**路径**：
- 爆款策略 + 矩阵防御
- 单款日消耗10万+
- DAU 50万+
- 全链路数据驱动优化
- 自研广告系统/聚合
- 月消耗：1000万+
- 月利润：500万+

## 七、实战调优方向

### 7.1 当ROI不达标时

| 问题 | 检查指标 | 优化方向 |
|------|---------|---------|
| 获客成本太高 | CPA > 15元 | 优化素材CTR、切ROI出价、自然量占比 |
| eCPM太低 | eCPM < 30 | 检查SDK接入、广告填充率、用户质量 |
| 用户不看广告 | 渗透率 < 30% | 优化广告点位、增加激励场景 |
| 留存差 | D1 < 20% | 优化新手引导、核心玩法、加载速度 |
| IPU低 | IPU < 4 | 增加广告场景（签到、复活、奖励翻倍） |

### 7.2 留存优化对盈利的影响

```
假设：
- CPA = 10元
- eCPM = 50元
- IPU = 6
- 渗透率 = 40%

场景A：D1=20%, D7=5%
  DAU系数 = 1 + 0.2 + 0.12 + 0.05×4 = 1.52
  LTV30 ≈ 0.12 × 1.52 = 0.18元
  ROI30 = 1.8% → 亏损

场景B：D1=35%, D7=12%（优化后）
  DAU系数 = 1 + 0.35 + 0.22 + 0.12×4 = 2.05
  LTV30 ≈ 0.12 × 2.05 = 0.25元
  ROI30 = 2.5% → 仍亏损，但改善40%

场景C：D1=50%, D7=22%（头部水平）
  DAU系数 = 1 + 0.5 + 0.35 + 0.22×4 = 2.73
  LTV30 ≈ 0.12 × 2.73 = 0.33元
  ROI30 = 3.3% → 仍低，说明CPA或eCPM也需优化
```

## 八、关键认知

### 8.1 国内IAA的残酷现实

1. **纯IAA很难盈利**：在CPA 10-20元的买量环境下，纯靠广告变现很难覆盖获客成本
2. **自然量是核心**：付费买量主要用于冷启动和维持DAU，真正盈利靠自然量带来的低成本用户
3. **留存是一切**：留存每提升5%，LTV可能提升20-30%
4. **混合变现是趋势**：IAA+IAP（IAAP）是当前最可行的盈利路径
5. **规模化才能盈利**：单款游戏DAU低于1万很难覆盖团队成本

### 8.2 盈利公式（简化版）

```
月利润 = (DAU × ARPU × 30) - (日新增 × CPA × 30) - 运营成本

盈利条件：DAU × ARPU > 日新增 × CPA + 运营成本/30

即：人均日收入 > 人均获客成本/留存周期 + 人均运营成本
```

### 8.3 给开发者的建议

| 阶段 | 目标 | 关键动作 |
|------|------|---------|
| 0-1月 | 验证留存 | D1>35%, D7>15% |
| 1-3月 | 验证变现 | eCPM>50, IPU>6, 渗透率>40% |
| 3-6月 | 规模放量 | DAU>3万, 日消耗>3万 |
| 6月+ | 利润优化 | 引入IAP, 降低CPA, 提升自然量占比 |
