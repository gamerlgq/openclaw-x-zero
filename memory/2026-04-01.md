### 已掌握的核心知识

#### Part 1: 核心概念
- **Agent Runtime**: 运行循环 → 消息处理 → 工具调用 → 结果返回
- **Session**: 会话生命周期、跨会话通信 (`sessions_send`)、子代理管理 (`subagents`)
- **Memory**: MEMORY.md 长期记忆 + memory/YYYY-MM-DD.md 日志
- **Context**: 消息上下文、工具可用性、技能触发
- **Agent Loop**: 消息循环、心跳机制、HEARTBEAT_OK 响应
- **Queue**: 命令队列、优先级排序
- **Streaming**: 流式输出、Chunking 分块
- **Compaction**: 历史压缩、摘要保留

#### Part 2: Gateway 架构
- **架构**: Gateway daemon + Agent runtime
- **CLI**: `openclaw gateway start/stop/restart/status`
- **配置**: ~/.openclaw/config.json + ~/.openclaw/gateway/config.json
- **协议**: WebSocket 连接、消息格式
- **安全**: authorized senders、权限控制
- **心跳**: HEARTBEAT.md 检查清单

#### Part 3: CLI 命令
- `openclaw status` - 系统状态
- `openclaw doctor` - 诊断工具
- `openclaw gateway` - Gateway 管理
- `openclaw cron` - 定时任务
- `openclaw hooks` - 事件触发
- `openclaw plugins` - 插件管理
- `openclaw sessions` - 会话管理
- `openclaw flows` - ClawFlow 管理

#### Part 4: 自动化系统
- **Cron Jobs**: `cron` tool - 定时任务调度
- **Heartbeats**: 周期性代理轮转，检查 HEARTBEAT.md
- **Hooks**: 事件驱动自动化 (`/new`, `/reset`, gateway startup)
- **Tasks**: Background Tasks 活动账本
- **ClawFlow**: 流程层机制，复杂任务编排
